# Volpe Floppy Disk #22

It was discovered that a certain tree model can randomly spawn a floppy disk billboard after being destroyed and disappear quickly afterwards. It was revealed by Robert Runesson that this disk is somehow related to in-game lore:

>**ROBERT RUNESSON:** (this is a small thing… linked to the big hunt in 3 ways… but it is also linked to a super-silly IRL thing, and some in-game lore things too… but primarily it’s was added to the game to share some love to you guys, to all fellow game devs that pour their souls and hearts into the games they work on…)

It is unknown if the IRL reference is relevant to the lore aspect, but the floppy disk is a reference to [The Secret of Monkey Islands' Stump Joke](https://www.youtube.com/watch?v=5imGrkuqCSc).

# Writings

The map has three kinds of writings that are found around the map. Some of which may be connected to lore, while others are possibly just filler text.

# Heart Motif

![[S03_Kyoto_Analysis_02.png]]

A heart-shaped cutout can be found used in multiple areas. It is possible that this is a reference to CNS' phrase "from CNS with love". If that is the case, then this could be a clue that CNS was behind [the gameshow being brought to this version of Kyoto](Seasons/S03/02_Intro_Vignette).
